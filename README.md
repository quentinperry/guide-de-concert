# Guide de concert

Guide du spectateur pour la *Grande messe en ut mineur* de Mozart (avec Bizet et Rameau), par le chœur et l'orchestre de l'Académie du Palais royal, sous la direction de Jean-Philippe Sarcos.

- `guide.html` : source de la page.
- `index.html` : page autonome générée par `./build.sh`, hébergeable telle quelle (GitHub Pages, etc.).
